# 모둠 활동 도우미

학생 명단을 등록하고 랜덤 또는 교사 직접 배정으로 모둠을 구성한 뒤, 모둠 활동 기록과 학생 개인별 기록(생활기록부 특기사항 작성용)을 남길 수 있는 웹앱입니다. 빌드 과정 없이 `index.html` 하나로 동작하며, GitHub Pages 등 정적 호스팅에 바로 올릴 수 있습니다.

중학교처럼 여러 학급을 가르치는 경우를 고려해 모바일에서 한 손으로 쓰기 쉽게 만들었고(하단 탭 내비게이션), 데스크톱에서도 그대로 사용할 수 있습니다.

## 주요 기능

- **교실**: 모둠이 한 줄로 나열되어 있지 않은 실제 교실(특히 음악실) 배치를 그대로 반영하기 위한 화면입니다. 칠판과 "교실 뒤"가 표시된 배경 위에, 가장 최근에 저장한 모둠 배정의 학생들이 이름표(각 모둠 색깔로 구분)로 뜹니다. 정사각형·삼각형·원형·아치형 등 미리 정해진 모둠 모양을 고르게 하는 대신, 이름표 하나하나를 손가락(마우스)으로 직접 끌어서 원하는 모양으로 자유롭게 배치할 수 있습니다(찰흙 만지듯 개인별 위치를 세밀하게 조정). 학생 개개인의 위치가 중요하지 않을 때는 각 모둠 위에 뜨는 작은 🧩 손잡이를 끌어서 그 모둠 전체(구성원 전원)를 한 번에 옮길 수도 있습니다. 배치는 자동으로 저장되고, "↺ 기본 배치로"로 언제든 처음 배열로 되돌릴 수 있습니다.
- **명단관리**: 명단관리 탭을 열면 바로 "이름 입력 후 Enter"만으로 학생을 추가하는 칸이 있습니다. 번호·성별 없이 이름만으로 명단을 만들 수 있어서, 정식 학급 번호가 없는 동아리·오케스트라부 같은 모임의 명단을 만들 때 특히 편합니다. Enter를 누른 뒤에도 입력창에 포커스가 그대로 남아 있어 이름을 계속 이어서 입력할 수 있습니다. 번호·성별·성적까지 갖춰 등록하고 싶으면 "＋ 번호·성별 등 자세히 추가" 버튼으로 자세한 등록 폼을 열 수 있습니다. 명단 표의 번호·이름·성적·메모는 칸을 클릭하면 바로 그 자리에서 값을 고쳐 쓸 수 있고("수정" 버튼 없이 즉시 반영, Enter로 확정), 성별은 공란 칸을 탭할 때마다 공란→남→여 순서로 바뀌는 버튼입니다. 여러 명 붙여넣기로 일괄 등록하거나, 엑셀(.xlsx) 파일·구글 스프레드시트에서 명단·기존 모둠 배정을 한 번에 가져올 수도 있습니다(시트가 여러 개면 하나씩 골라서). 모둠 배정도 준비 작업이라 이 탭 안의 "🎲 모둠 관리" 버튼으로 여기서 함께 처리합니다.
- **모둠 자동 배정 (명단관리 안)**: 조장이나 따로 앉혀야 할 학생처럼 미리 정해야 할 학생은 먼저 학생 칩을 클릭(또는 드래그)해 원하는 모둠에 직접 넣어두고, 나머지는 조건을 골라 "자동 배정"을 누르면 미배정 학생만 채워집니다(이미 넣어둔 학생은 그대로 유지). 고를 수 있는 조건은 완전 랜덤, 남녀 성비 균등(명단의 성별 기준), 이전 성적 골고루(명단의 성적 기준으로 모둠별 합계를 비슷하게), 성별+성적 균형, 최대한 섞기(이전에 저장된 회차들과 되도록 같은 모둠이 겹치지 않게)입니다. "↺ 전체 미배정으로"로 언제든 처음부터 다시 배정할 수 있습니다.
- **전체 학급 한 번에 만들기**: "학급, 번호, 이름" 형식으로 여러 반의 명단을 한꺼번에 붙여넣거나, 반별 시트가 있는 엑셀 파일을 올려 "시트 전부 학급으로 한 번에 만들기"를 누르면, 학급마다 자동으로 학급이 생성되고 각 학급에 해당 명단이 채워집니다. 지금 보고 있지 않은 학급도 함께 만들어져서, 상단 학급 배지에서 바로 골라 들어갈 수 있습니다.
- **진도기록**: 차시별로 그날 나간 진도/활동 내용을 남깁니다. 차시 번호는 옆의 −/＋ 버튼으로 클릭만으로 바꿀 수 있습니다. 등록된 진도 항목을 누르면 그 자리에 메모 칸이 펼쳐져서, 짧은 한 줄 진도 내용 외에 수업 중 특이사항이나 다음 시간에 참고할 점 같은 더 자세한 메모를 남길 수 있습니다. 한 학급에서 쓴 내용을 "🔁 전체 적용" 버튼으로 지금까지 만든 모든 학급에 그대로 밀어넣을 수 있어서, 같은 진도로 나가는 여러 반은 한 번만 입력하면 됩니다. 물론 반마다 진도가 다르게 나갈 때는 각 학급에서 따로따로 기록해도 됩니다. "전체 학급 비교" 화면에서는 학급을 행으로, 차시를 열로 하는 표로 여러 학급의 진도를 위아래로 훑어보며 한눈에 비교할 수 있습니다(새로고침 시점의 스냅샷이므로 최신 내용을 보려면 새로고침하세요).
- **활동기록**: 앱을 열거나 학급을 전환하면 기본으로 뜨는 화면입니다. 회차의 모둠들을 한 화면에서 보면서, 모둠 전체 기록을 바로 남기고 학생 한 명을 탭하면 그 자리에서 개인 기록을 남길 수 있습니다(탭 전환 없이 한 화면에서 완결). 상단에는 그 시간에 반 전체가 한 활동을 한 줄로 남기는 칸이 있습니다. 학생을 선택하면 그날그날의 활동을 🟢 잘함 / 🟡 노력중 / 🔴 노력요함 신호등 버튼 한 번으로 바로 기록할 수 있고, 그동안 받은 신호등이 학생 이름 옆에 작은 점으로 다닥다닥 붙어서 한눈에 쌓인 게 보입니다(이런 단순 평가는 세로로 쌓이지 않고 날짜 배지가 가로로 나열됩니다). 학생 이름 옆의 "👑 조장" 버튼으로 조장을 지정/해제하고, "🚫 결석" 버튼으로 결석을 바로 기록할 수 있습니다. 필요하면 음악 활동·수업 활동·교과 역량·성장 중 카테고리의 키워드를 골라 메모에 덧붙일 수 있습니다. "학생별 전체보기"에서는 학생 이름을 누르면 그 이름 바로 아래에 그 학생의 모든 기록이 펼쳐져(아코디언 방식) 회차와 상관없이 모아볼 수 있어 생기부 작성 시 참고하기 좋습니다. 이 목록의 각 학생 이름 옆에는 최근 신호등 평가 최대 10개가 작은 점으로 표시되어, 펼쳐보지 않아도 그 학생의 최근 활동 경향을 한눈에 파악할 수 있습니다.
- **기록 한 번에 복사하기**: 학생 기록은 파일로 내려받는 대신 클립보드로 바로 복사됩니다. 한 학생만 복사할 수도 있고, "학생별 전체보기"의 "전체 학생 기록 한 번에 복사"로 반 전체 학생의 기록을 한 번에 복사해 문서에 붙여넣을 수도 있습니다.
- **기록 구분 직접 관리**: 자율활동/동아리활동 같은 정해진 항목 대신, 기록 화면에서 "+ 새 구분 추가"로 필요한 구분(예: 수행평가, 태도)을 직접 만들어 쓰고 설정 탭에서 정리할 수 있습니다.
- **학급 빠른 전환**: 상단 가운데의 학급 배지를 누르면 지금까지 만든 학급 목록이 드롭다운으로 뜨고, 클릭 한 번으로 전환하거나 "+ 새 학급"으로 바로 추가할 수 있습니다. 매번 코드를 다시 입력할 필요가 없습니다.
- **넓게 쓰는 상단바**: 앱 제목은 왼쪽, 동기화 상태와 설정(⚙️) 버튼은 오른쪽, 학급 배지는 그 사이 가운데에 있어 화면 폭을 낭비하지 않습니다. 설정 화면은 자주 쓰는 화면이 아니라서 하단 탭에 넣지 않고, 우측 상단 ⚙️ 버튼을 눌러야만 들어갈 수 있습니다.
- **탭 순서**: 교실 - 명단관리 - 활동기록 - 진도기록 순서로 배치했습니다.
- **여러 기기 동기화**: Firebase(Firestore)를 연결하면 같은 "학급 코드"를 사용하는 PC·태블릿·휴대폰에서 실시간으로 데이터가 동기화됩니다. 연결하지 않아도 브라우저 로컬 저장소에 자동 저장되어 계속 사용할 수 있습니다.
- **구글 스프레드시트 연동**: 명단/모둠배정/모둠기록/개인기록/수업활동을 스프레드시트 5개 탭으로 내보내거나, 기존 스프레드시트에서 명단을 불러올 수 있습니다.

> MBTI·선호역할 같은 특정 설문 항목은 이 앱의 일반 기능에서 제외했습니다. 엑셀로 가져올 때도 모둠/학번/이름과 특이사항 메모만 반영됩니다. 명단관리의 "성적(선택)"은 자동 배정의 "성적 골고루" 조건에만 쓰이는 범용 항목이에요.

## 처음 사용하기 (설정 없이)

`index.html`을 웹서버에 올리거나 로컬에서 바로 열면, 별도 설정 없이도 이 브라우저(이 기기)에 데이터가 저장되며 모든 기능(명단/배정/기록)을 사용할 수 있습니다. 여러 기기에서 함께 쓰려면 아래 Firebase 설정이 필요합니다.

## 여러 기기 동기화 설정 (Firebase)

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 새 프로젝트를 만듭니다.
2. **Firestore Database**를 생성합니다 (프로덕션 모드 권장).
3. **Firestore 규칙**을 아래와 같이 설정해, 로그인(익명 포함)한 사용자만 접근하도록 합니다.
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /classes/{classId} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```
4. **Authentication → Sign-in method**에서 "익명(Anonymous)" 로그인을 사용 설정합니다.
5. 프로젝트 설정 → "내 앱"에서 웹 앱을 추가하고, 표시되는 설정 객체(JSON)를 복사합니다.
6. 앱의 **설정** 탭에 붙여넣고 "적용"을 누릅니다.
7. 상단 학급 배지를 눌러 다른 기기와 똑같은 학급 코드를 추가/선택하면 같은 데이터가 실시간으로 공유됩니다. (학급 코드는 비밀번호 역할을 겸하므로 외부에 공개되지 않도록 주의하세요.)

## 구글 스프레드시트 연동 설정

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들거나 선택합니다.
2. **API 및 서비스 → 라이브러리**에서 "Google Sheets API"를 사용 설정합니다.
3. **API 및 서비스 → OAuth 동의 화면**을 구성합니다 (테스트 단계에서는 본인 계정을 테스트 사용자로 추가).
4. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션**을 선택하고, "승인된 자바스크립트 원본"에 앱을 호스팅할 주소(예: `https://username.github.io`, 로컬 테스트 시 `http://localhost:포트`)를 추가합니다.
5. 생성된 클라이언트 ID를 앱의 **설정** 탭에 입력합니다.
6. "Google 계정 연결"로 로그인한 뒤, 명단관리 탭에서 스프레드시트 URL/ID와 범위(예: `시트1!A1:D100`)를 입력해 명단을 가져오거나, 설정 탭에서 전체 데이터를 새 스프레드시트로 내보낼 수 있습니다.

`spreadsheets` 범위는 민감 범위로 분류되어 있어, 앱을 검증받지 않은 상태에서는 OAuth 동의 화면에 등록된 테스트 사용자 계정으로만 로그인할 수 있습니다. 학교 내 소규모 사용에는 테스트 사용자 등록만으로 충분합니다.

## 모바일 홈 화면에 추가하기

크롬(안드로이드)에서는 메뉴 → "홈 화면에 추가", 사파리(아이폰)에서는 공유 버튼 → "홈 화면에 추가"를 누르면 **modoom**이라는 이름과 🧩 퍼즐 아이콘으로 바탕화면에 추가됩니다. 아이콘을 다시 바꾸려면 `manifest.webmanifest`와 `icons/` 폴더의 이미지를 교체하세요.

## 배포

빌드 과정이 없으므로 `index.html`을 GitHub Pages, Netlify 등 아무 정적 호스팅에 올리면 바로 동작합니다. GitHub Pages를 쓴다면 저장소 설정 → Pages에서 배포할 브랜치를 지정하세요.

## 데이터 백업

Firebase나 구글 계정 없이도 설정 탭의 "백업 파일 저장/불러오기"로 전체 데이터를 JSON 파일로 내려받거나 복원할 수 있습니다.
